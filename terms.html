Because Selene is self-hosted, you are responsible for everything needed to run it, including:

  • A computer / host that meets the requirements in the setup guide (Windows for the packaged .exe build) and stays online when you want the bot online;
  • Your own Discord bot application and token. You create the bot in the Discord Developer Portal, invite it to your server with the permissions in the guide, and keep its token secret.   • Updates & security for your operating system, network, and any Minecraft accounts you use with Selene;
  • Compliance with the rules of every Discord server and Minecraft server where you use Selene.

If you get stuck, follow the current setup guide in the Selene Discord first, then open a support ticket with what you tried and any error messages (redacting tokens and passwords).
